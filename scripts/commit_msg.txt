feat(api): consumer API gateway — /api/v1/* with sk_live_ bearer auth

The "door to the vault" is now open. Users can create an sk_live_ key in
the dashboard and immediately use it to call /api/v1/*.

NEW:
- src/lib/api-gateway.ts — auth + audit + correlation-id layer
  - extractBearerToken: parses `Authorization: Bearer sk_live_...`
  - authenticateRequest: validates token via findApiKeyByRawSecret
  - recordApiEvent: fire-and-forget write to api_key_events
  - touchKeyUsage: fire-and-forget update of api_keys.lastUsedAt
  - getRequestId: echoes client X-Request-Id or generates one
  - gatewayError: standard { error: { code, message, details } } shape

- src/app/api/v1/[...path]/route.ts — catch-all gateway
  - Handles GET/POST/PUT/PATCH/DELETE via single gateway() function
  - OPTIONS short-circuits with Allow header (CORS preflight)
  - Special-cases /v1/_meta (discovery endpoint)
  - Matches all 399 documented endpoints via api-reference catalogue
  - Returns 501 NotImplemented for documented-but-not-implemented
  - Returns 404 for unknown paths, 405 for wrong method
  - Every authenticated request gets audit log + lastUsedAt touch
  - X-Request-Id + X-Musicosy-Version headers on every response

RESPONSE CODES:
  200 — handler succeeded (only /v1/_meta today)
  401 — missing/invalid API key
  404 — endpoint not in catalogue
  405 — method not allowed for this path
  501 — documented but not yet implemented

FRONTEND AUDIT (no changes needed):
  All 5 dashboard pages are "use client" with useEffect data fetching.
  Layout is a thin server component with ZERO DB calls.
  HTML response contains zero inline user data.
  Render times: 38-77ms warm.

End-to-end verified:
  - Valid key + documented endpoint -> 501 with endpoint metadata
  - Audit events written to api_key_events (11 rows verified)
  - api_keys.lastUsedAt updated on every authenticated request
  - X-Request-Id preserved from client or auto-generated
